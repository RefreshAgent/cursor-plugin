# Audit this website's SEO

Use the `seo-optimization` skill and RefreshAgent MCP tools where available.

1. Identify the website's framework, base URL, routes, templates and canonical URL strategy.
2. Inspect current robots, sitemaps, metadata, headings, structured data, crawlability and linking behavior in relevant files.
3. Research external search or content evidence with RefreshAgent, especially information gain and content differentiation. If authorized site analytics are available, investigate losses, content decay and CTR opportunities.
4. Return a prioritized table showing issue, page or file, evidence source, confidence, suggested fix and how to verify.
5. Separate observed findings from hypotheses; never fabricate rankings, keyword volumes or traffic.
6. This command is **audit-only**. Do not modify project files, deploy or invoke paid operations without authorization.
